# 🏦 Bank Marketing Analytics Dashboard | Power BI

## 📌 Project Overview

This project analyzes bank marketing campaign data using Microsoft Power BI. The dashboard helps explore customer responses to marketing campaigns and identify patterns related to campaign outcomes.

## 🎯 Project Objectives

* Analyze customer responses to bank marketing campaigns.
* Understand customer demographics and campaign engagement.
* Explore campaign outcomes using interactive visualizations.
* Present key metrics to support data-driven marketing decisions.

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Cleaning and Transformation
* Data Visualization

## 📊 Dashboard Features

* 👥 Customer overview and KPI cards
* 📈 Marketing campaign analysis
* 🧑 Customer age and demographic analysis
* 📞 Campaign contact analysis
* 🎯 Campaign outcome exploration
* 🎛️ Interactive slicers and filters

## 🧹 Data Preparation

* Imported the bank marketing dataset.
* Split columns correctly where necessary.
* Checked data types and transformation errors.
* Prepared the data for reporting and visualization.

## 💡 Key Learnings

* Importing and transforming data in Power BI
* Creating DAX measures
* Building KPI cards and charts
* Using slicers to filter dashboard visuals
* Designing an interactive analytics dashboard
